# SYLO

SYLO is a collaborative project management application focused on projects and tasks.

## Main Features

- User registration and login
- Email verification
- Project management
- Project collaboration
- Task management
- Multiple task assignees
- Task statuses and deadlines
- Project progress tracking
- Password recovery
- Overdue email reminders

## Tech Stack

### Frontend
- React
- React Router
- Axios
- Context API
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
- Nodemailer

### API Documentation and Testing
- Swagger
- Postman
